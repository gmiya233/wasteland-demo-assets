# GDD_T0_006：建造、机器与生产

版本：v0.1  
状态：待审核

## 1. 目标

让玩家建立能够缓解生存压力的小型据点，并最终完成第一套蒸汽发电设施。通用机器模型继续为未来加工设备和自动化预留扩展能力。

## 2. 建造规则

- 从建造菜单选择设施，进入预览状态。
- 预览显示占地、朝向、输入输出端口和放置合法性。
- 合法条件包括地面支撑、无严重重叠、在允许坡度内且玩家可达。
- 确认时一次性扣除材料并生成设施。
- 取消预览不消耗材料。
- 使用扳手拆除己方设施；T0默认返还全部核心材料，消耗品不返还。
- 装有物品或正在工作的设施拆除前必须确认，内容优先转入玩家背包，剩余落地。

| 设施 | 阶段 | 主要作用 |
|---|---|---|
| 火堆 | T0-1 | 取暖、烹饪和煮水 |
| 简易工作台 | T0-3 | 工具、设施和基础零件制作 |
| 简易储物箱 | T0-3 | 集中存储资源 |
| 床铺 | T0-3 | 恢复疲劳和推进时间 |

| 简易锅炉 | T0-5 | 将燃料与水转化为低压蒸汽 |
| 蒸汽发电机 | T0-5 | 将低压蒸汽转化为电力 |
| 测试电灯 | T0-5 | 验证首次电力输出 |

## 4. 通用机器状态

- 未配置：没有有效配方或连接。
- 待机：条件满足但没有任务。
- 缺少输入：原料不足。
- 缺少能源：蒸汽不足。
- 工作中：按周期推进加工。
- 输出堵塞：产物无处存放。
- 禁用：玩家主动关闭。
- 故障：为未来维修系统预留；T0默认不随机故障。

任一暂停状态都必须显示具体原因和恢复条件。

## 5. 机器处理规则

- 机器通过能力标签匹配配方。
- 机器持有输入仓、输出仓、任务状态和能源端口。
- 生产速度和能源消耗来自机器与配方共同计算。
- T0一台机器同时只执行一种配方，允许玩家切换。
- 切换配方不得删除已有物品；不兼容输入需要玩家取出。
- 离开机器界面或离开附近区域不影响生产。

## 6. T0终局设施链

建议关系：水与燃料 → 简易锅炉 → 低压蒸汽连接 → 蒸汽发电机 → 最小电力连接 → 测试电灯。

玩家手动补充水和燃料。电灯连续点亮规定时间即完成T0。蒸汽缓冲罐、加工机和自动物流均不是当前必需项。

## 7. UI最小信息

- 当前工作模式或配方
- 输入与输出库存
- 加工进度
- 当前工作状态
- 能源输入、输出与连接状态
- 预计产物
- 停机原因

世界空间表现至少包括运行音效、运动部件或蒸汽效果，以及停机状态变化。

## 8. 扩展约束

- 机器核心不引用特定能源实现。
- 端口数据独立于模型朝向，并可映射到模型连接点。
- 机器定义、配方和运行实例分离。
- 模块、升级、多方块结构只保留数据扩展位，T0不实现。
- 每个建造实例具有稳定实例ID用于存档和连接关系。
