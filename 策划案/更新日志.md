# Wasteland Industrial Demo 策划案更新日志

本文件记录已经写入仓库的策划案版本变更。尚处于讨论、但未写入正式文档的内容不计入日志。

## T0 Design Draft v0.9 — 2026-08-15

### 地基配方调整

- 地基组件配方由铁板×10调整为铁板×4、泥土×2，仍要求铁锤完成捶打加工并消耗1点耐久。
- 自由探索目标同步改为铁板0/4、泥土0/2、铁锤0/1。
- 铁板与铁锤主要在城区准备，泥土在郊外土壤地形取得，使玩家自然进入基地候选区域。

### 世界空间结构

- 出生城市保持固定六区和32地块，城市外改为从2至3个连接口自动延长程序化公路。
- 新增城市边缘、近路基地候选区、远路基地候选区、郊外资源带、石料矿场和远端公路边界的连续空间结构。
- 基地候选带至少提供两个不同取向的建造区域，并保证至少一个位置可合法放置首块地基。
- 相邻城市边缘间隔保持6—10分钟徒步，理想值8分钟；达到10分钟后的下一合法大型节点强制生成城市。
- 新增`BLD_T0_012_城区郊外与城市间隔.md`与`DB_T0_010_WorldSpatialLayout.csv`。
- 后续城市、石料矿区、基地候选地和稀疏建筑统一依附公路图生成。
- 两城之间每0.75至1.5分钟产生地点候选，只有35%实际生成，目标为每段出现约2至4个稀疏地点。
- 每对城市之间至少安排一个矿区候选和一个可建造开阔区。
- 新增`BLD_T0_014_公路网络与地点程序生成.md`与`DB_T0_012_RoadGenerationRules.csv`。
- 修正沿路地点概率：每个候选点先统一进行一次35%启用判定，成功后再按权重选择至多一个地点，避免六类地点各自判定导致同点重叠生成。
- 在空间表中补充`road_network`父级节点，统一承载沿路资源带、石料矿场、稀疏地点和后续城市。
- 明确城区建筑文档只负责出生城市和单个城市模板内部；城际道路与沿路节点由公路生成文档负责。

### 背包容量调整

- 三级背包容量由12/20/30格扩大为20/30/42格。
- 对应二维网格由3×4、4×5、5×6调整为4×5、5×6、6×7。
- 同步更新总纲、生存需求、教学、背包规则、第一人称UI和背包原型。
- 通用容器原型仍保持4×5，不随玩家背包容量调整。
- 玩家开局改为没有背包，只有左右手两个实际持有位。
- 新手住宅固定放置一级背包，内部预装铁铲×1、面包×2和饮用水×2。
- 背包改为具有独立实例与内部容器状态的可装备物品，取下、丢弃和重新拾取时内容不会丢失。
- 禁止背包嵌套；升级旧背包前必须清空内部物品。
- 新增三级背包物品和`DB_T0_011_BackpackDefinitions.csv`。
- 新增便携背包状态机，覆盖世界放置、左右手持、装备槽和固定容器存放。
- 确定两个非空背包使用原子交换，内部物品不自动搬运；地面换包时旧背包占用新背包原来的世界位置。
- 快捷栏实例绑定在背包取下后保留但暂时失效，重新装备原背包后恢复。
- 随身制作队列进行中禁止取下或交换背包，避免锁定材料跨容器结算。
- 新增`GDD_T0_013_便携背包装备与换包.md`。
- 无背包时快捷栏`3`至`6`号保持可见但整体置灰并禁用，数字键不可选择，鼠标滚轮只循环左右手位；装备背包后恢复。

## T0 Design Draft v0.8 — 2026-08-14

### 城区建筑生成

- 新增城区建筑生成逻辑文档。
- T0采用“手工道路、街区与地块＋种子化建筑和内容”的混合生成模式。
- 建立住宅、商业、工业和城郊过渡区四层空间结构。
- 确定独栋住宅、便利店、餐厅、小型工厂和空地的首版分区权重。
- 新手住宅保持固定生成，普通建筑按地块允许类型抽取。
- 建筑内部不程序化生成房间，只启用预制的容器、露天物品和装饰插槽。
- 汽车使用独立道路、车道与停车区插槽，不占用建筑地块。
- 加入相邻重复限制、入口可达性检查、失败地块局部回退与稳定实例ID规则。
- 建筑、入口、容器、汽车和战利品只在世界首次创建时生成，读档与返回区域不会刷新。
- 确认T0首版采用一张不规则固定道路地图，不使用随机道路或棋盘式街区。
- 固定地图重新划分为四个住宅区、一个商业区和一个工业区，每个区域包含若干建筑地块。
- 首轮灰盒规划32个建筑地块：住宅22个、商业6个、工业4个。
- 主干道采用弯曲走向，并连接旧城环路、北部支路、东部住宅半环路、南部边缘路和工业支路。

### 开局流程调整

- 强制开局引导改为在玩家成功制作简易撬棍时结束。
- 取消制作撬棍后继续指定受限容器、固定探索路线和强制前往郊外的旧流程。
- 引导结束后设立非强制目标“准备地基材料”：铁板×10、可用铁锤×1。
- 目标只显示材料进度，不标记固定建筑、容器或最短获取路线。
- 玩家可以自由探索住宅、便利店、工厂、餐厅和汽车，并自行决定何时离开城区。
- 材料齐全后目标更新为“制作地基，并在郊外建立基地”。
- 成功放置第一块地基仍负责登记基地锚点和开启科技树，但不再作为新手引导完成条件。
- 地基物品与配方的解锁里程碑由`tutorial_5`调整为`t0_3`。
- 地基所需铁板不设置固定保底容器，正式刷新权重将在城区战利品设计中确定。

## T0 Design Draft v0.7 — 2026-08-13

### 新增

- 新增独立的《流体系统》策划文档，统一管理流体分类、机器端口、管道连接、缓存和流量规则。
- 新增独立的《电力系统》策划文档，统一管理GE单位、发电、用电器缓存、导线连接和临时供电规则。
- 新增科技节点“地下水源钻探”“简易管道”和“基础电力连接”。
- 新增物品：简易管道、绝缘铜导线、一次性电池。
- 新增建筑设施：地下水井。
- 新增简易管道配方：铁棍×1、铁板×1、铁螺丝×1，使用铁锤和铁螺丝刀，在初级工作站产出1米管道。

### 流体系统

- 将水与低压蒸汽统一归类为`Fluid`：
  - 水：`Fluid.Water`
  - 低压蒸汽：`Fluid.Steam.LowPressure`
- 简易管道可以运输所有`Fluid`类型，具体机器端口仍可限制允许输入的流体。
- 简易管道采用两点逻辑连接：手持管道依次右键两个兼容端口，按直线距离向上取整消耗管道。
- 管道不生成世界模型，不检测路径、障碍、坡度、管径与压力。
- 简易管道尺寸为1×1，每个数量代表1米，单格最多堆叠100米。
- 确认三条T0流体连接：
  - 地下水井 → 电动水泵
  - 电动水泵 → 小型园艺室
  - 简易锅炉 → 蒸汽发电机
- 电动水泵抽水量为100 ml/tick，自带1000 ml缓存。
- 小型园艺室自带4000 ml缓存；正常生产消耗50 ml/tick，速度为×1.0；缺水时不消耗水，仍以×0.2速度生产。

### 电力系统

- 确认电力单位为GE，固定模拟频率为每秒4 tick。
- 单台蒸汽发电机输出10 GE/tick，即40 GE/s。
- T0用电器默认具有1000 GE内部容量，具体设备允许覆盖该数值；新建设备默认从0 GE开始充电。
- 电动水泵耗电2 GE/tick，即8 GE/s；1000 GE满电缓存可独立运行125秒。
- 绝缘铜导线沿用管道的两点逻辑连接与长度消耗规则。
- 绝缘铜导线尺寸为1×1，每个数量代表1米，单格最多堆叠100米。
- 明确铜线是电子材料，绝缘铜导线才可以建立机器电力连接。
- 一次性电池不可合成、充电或维修，只能通过城区搜索获得，可临时启动电动水泵。
- 外部发电优先于应急电池；备用电池必须由玩家手动启用，避免自动浪费。

### 流程与科技树

- T0最终工业流程调整为：

  `地下水钻探 → 地下水井 → 水泵与园艺室水路 → 锅炉产汽 → 蒸汽发电 → 导线供电 → 稳定抽水`

- 区分两个里程碑：
  - 首次抽水：允许使用一次性电池完成。
  - 稳定供水：必须由蒸汽发电机通过绝缘铜导线驱动水泵，作为T0完成条件。
- 科技主线负责蒸汽发电和电力连接，农业支线负责地下水、简易管道和园艺室，两条线路在电动水泵节点汇合。

### 背包与UI

- 普通物品继续保持不可堆叠。
- 简易管道与绝缘铜导线成为按米计量的特殊堆叠物品。
- 管道和导线支持数量合并与拆分，其他普通物品仍不提供堆叠和拆分。
- 删除发电机UI中遗留的“电灯连接状态”，改为显示蒸汽输入、GE/t输出和绝缘铜导线连接状态。

### 数据结构

- 修正蒸汽标签，将旧`Energy.Steam.LowPressure`统一替换为`Fluid.Steam.LowPressure`。
