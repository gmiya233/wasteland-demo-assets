# GDD_T0_005：制造、配方与工具

版本：v0.6
状态：基础材料、工具、焦炉与电子材料配方已更新

## 1. 本轮重构原则

旧版原材料、加工件、工具和配方全部撤销，不再视为已确认设计。当前只保留已经讨论确认的第一批物品与开局配方，后续根据实际流程逐项增加。

- 物品主类型按照物品本身的性质划分，不按照获取地点划分。
- 获取地点、容器类型和拆解来源属于生成配置，不属于物品主类型。
- 相近材料不为写实而过度细分；T0统一使用“铁棍”，不增加铁条、钢筋等近似基础物品。
- 配方中的材料会被消耗；工具只提供加工能力并损失耐久。
- 当前尚未确认的配方不得继续保留占位成本。
- Tab默认只打开背包；玩家点击背包右上角`制作`按钮后，右侧展开配方图标网格和配方详情。

### 1.1 随身制作队列

- 随身制作支持单次、连续和批量制作，并按队列顺序执行。
- T0制作队列最多同时存在3项。
- 每个制作项开始前校验并锁定该项材料。
- 空间校验先模拟移除材料，再验证并预留产物需要的连续格位。
- 材料释放出的格位可以被本次产物预留。
- 队列确认时预留全部队列产物空间；预留位置显示半透明产物占位，不能放入其他物品。
- 玩家可以关闭制作界面，制作队列继续运行。
- 关闭后在游戏画面右上角显示当前产物、队列数量和进度。
- 玩家在随身制作期间可以移动，但移动速度降低；具体倍率等待原型测试。
- 制作减速与饥饿、口渴减速同时存在时取最低倍率，不执行乘法叠加。
- 制作完成后产物进入预留位置，不能因关闭界面而掉落或丢失。

## 2. 当前物品主类型

| 主类型 | 定义 | 当前子类 |
|---|---|---|
| `Consumable` | 使用后被消耗并改变玩家状态 | `Food`、`Drink` |
| `Material` | 用于制造、建造、维修或加工 | `Metal`、`Stone`、`Wood` |
| `Tool` | 用于制造或改变世界对象状态，可具有耐久 | `Pry`、`Hammer`、`NailPull` |

材料可以附加形态标签，例如铁棍使用`Form.Rod`、铁板使用`Form.Plate`。形态标签用于配方匹配，不建立新的主类型。

## 3.1 基础加工配方

- 金属板：对应金属锭×2，使用铁锤，产出金属板×1。
- 金属棍：对应金属锭×1，使用铁锉刀，产出金属棍×1；当前只有铁棍和铜棍。
- 金属线：对应金属板×1，使用铁剪线钳，产出金属线×1；当前包括铁丝、铜线和锡线。
- 金属粉：对应金属锭×1，使用研磨碗，产出金属粉×1。
- 铁螺栓：铁棍×1，使用铁锯，产出铁螺栓×2。
- 铁螺丝：铁螺栓×1，使用铁锉刀，产出铁螺丝×1。
- 徒手木棍：木材×1产出木棍×1。
- 工作站木棍：木材×1，使用铁锯，产出木棍×4。
- 木板：木材×1，使用铁锯，产出木板×2。

## 4. 当前确认配方

### 制作简易撬棍

| 字段 | 内容 |
|---|---|
| 输入 | 铁棍×1、石头×1 |
| 输出 | 简易撬棍×1 |
| 加工方式 | 徒手制作 |
| 必需工具 | 无 |
| 必需设施 | 无 |
| 解锁方式 | 取得铁棍后显示，并引导寻找石头 |
| 制作时间 | 待程序原型后确定 |

行为解释：玩家以坚硬地面作为支撑，用石头反复敲击铁棍，使一端弯曲并形成可以插入缝隙的简易工具。石头在配方中被消耗，代表加工过程中破裂或失去继续使用价值。

### 制作地基组件

| 字段 | 内容 |
|---|---|
| 输入 | 铁板×10 |
| 输出 | 地基组件×1 |
| 加工方式 | 捶打加工 |
| 必需工具 | 铁锤，`Tool.Hammer` |
| 工具消耗 | 成功制作后扣除1点耐久 |
| 必需设施 | 无，作为新手建造教学配方 |
| 解锁方式 | 获得铁锤并进入郊外基地教学阶段 |
| 制作时间 | 待程序原型后确定 |

地基组件由十块铁板通过捶打、搭接和整形制成。当前配方将连接结构抽象进铁板投入，不额外引入紧固件物品。

## 5. 工具参与配方与耐久规则

后续配方应分别记录消耗材料和必需工具：

- `inputs`：会被配方消耗的物品及数量。
- `tool_tag`：执行配方必须具备的工具能力。
- `tool_durability_cost`：成功完成后扣除的工具耐久。
- `process_tag`：徒手、工作台、加热或机械加工等能力。
- `required_station`：需要的具体工作环境；如无则允许随身制作。

简易撬棍是开局特例：石头作为一次性加工材料直接消耗，不要求先实现通用工具槽。

所有工具最大耐久统一为`128`。每次成功完成一次交互、一个成品、一批材料加工或一次构件拆取时消耗`1`点耐久；失败、取消和中断不消耗。耐久降至`0`时工具立即从库存、快捷栏、手持状态或工具位中自动销毁，不生成损坏工具或返还材料。若制作队列因此缺少工具，未完成项目暂停且尚未加工的材料不被消耗。
