# GDD_T0_005：制造、配方与工具

版本：v0.3
状态：重构中

## 1. 本轮重构原则

旧版原材料、加工件、工具和配方全部撤销，不再视为已确认设计。当前只保留已经讨论确认的第一批物品与开局配方，后续根据实际流程逐项增加。

- 物品主类型按照物品本身的性质划分，不按照获取地点划分。
- 获取地点、容器类型和拆解来源属于生成配置，不属于物品主类型。
- 相近材料不为写实而过度细分；T0统一使用“铁棍”，不增加铁条、钢筋等近似基础物品。
- 配方中的材料会被消耗；工具只提供加工能力并损失耐久。
- 当前尚未确认的配方不得继续保留占位成本。

## 2. 当前物品主类型

| 主类型 | 定义 | 当前子类 |
|---|---|---|
| `Consumable` | 使用后被消耗并改变玩家状态 | `Food`、`Drink` |
| `Material` | 用于制造、建造、维修或加工 | `Metal`、`Stone`、`Wood` |
| `Tool` | 用于制造或改变世界对象状态，可具有耐久 | `Pry`、`Hammer`、`NailPull` |

材料可以附加形态标签，例如铁棍使用`Form.Rod`、铁板使用`Form.Plate`。形态标签用于配方匹配，不建立新的主类型。

## 4. 当前唯一确认配方

### 制作简易撬棍

| 字段 | 内容 |
|---|---|
| 输入 | 铁棍×1、石头×1 |
| 输出 | 简易撬棍×1 |
| 加工方式 | 徒手制作 |
| 必需工具 | 无 |
| 必需设施 | 无 |
| 解锁方式 | 取得铁棍后显示，并引导寻找石头 |
| 制作时间 | 待程序原型后确定 |

行为解释：玩家以坚硬地面作为支撑，用石头反复敲击铁棍，使一端弯曲并形成可以插入缝隙的简易工具。石头在配方中被消耗，代表加工过程中破裂或失去继续使用价值。

## 5. 工具参与配方的规则

后续配方应分别记录消耗材料和必需工具：

- `inputs`：会被配方消耗的物品及数量。
- `tool_tag`：执行配方必须具备的工具能力。
- `tool_durability_cost`：成功完成后扣除的工具耐久。
- `process_tag`：徒手、工作台、加热或机械加工等能力。
- `required_station`：需要的具体工作环境；如无则允许随身制作。

简易撬棍是开局特例：石头作为一次性加工材料直接消耗，不要求先实现通用工具槽。
