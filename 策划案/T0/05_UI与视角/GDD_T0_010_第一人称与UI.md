# GDD_T0_010：第一人称与UI

版本：v0.3
状态：背包、制作入口与左右手快捷位已更新

## 1. 目标

采用第一人称视角强化废墟探索、资源辨认和设备操作。HUD使用简洁现代风格，探索时保持低遮挡，需要操作时才展开详细信息。

## 2. 已确认规则

- 游戏采用第一人称视角。
- 完整物品栏打开时游戏世界不暂停。
- T0快捷栏为6位，其中`1`、`2`号为不占背包网格的左右手位，系统预留后续扩容能力。
- 第一人称显示手持工具和当前可用物品。
- HUD采用现代、清晰、低装饰的视觉风格。
- 饥饿和口渴显示在快捷栏上方。
- 物品栏打开时玩家不能移动，但世界继续运行。
- T0只显示悬浮的手持工具，不制作第一人称手臂。
- 快捷栏同时支持数字键和鼠标滚轮切换。
- 物品栏只覆盖部分屏幕，保留周围环境可见。
- 完整物品栏采用战术搜刮式二维网格；Tab默认只显示背包，点击背包右上角制作按钮后在右侧展开制作窗口；搜刮界面固定左侧背包、右侧容器。

## 3. 探索HUD布局

### 屏幕中心

- 默认显示低透明度小型准星。
- 对准可交互目标时，准星增强并显示目标反馈。
- 交互提示位于准星下方，包括按键、动作、目标和缺失条件。
- 世界拾取、打开容器和持续撬锁统一使用`F`；打开背包或容器UI后世界交互提示和准星物品信息隐藏。
- 持续交互使用准星外围进度或紧邻准星的简洁进度条。

### 屏幕底部中央

- 显示6位快捷栏；`1`、`2`号明确标注左手与右手，并与`3`至`6`号普通快捷引用位形成视觉分组。
- 每个位置显示快捷键、物品图标和工具耐久；T0当前物品不堆叠。
- 左右手位中的物品不占背包网格；`3`至`6`号仍引用背包物品并继续占用背包空间。
- 当前选中格使用清晰边框，不使用大面积高亮遮挡视野。
- 饥饿与口渴条显示在快捷栏上方。
- 数字键`1`至`6`直接选择对应格，鼠标滚轮循环选择上一格或下一格。

### 临时信息

- 获得物品、配方解锁和工具低耐久提示显示在屏幕侧边或快捷栏上方。
- 短时间获得的同类物品合并显示。
- 常规提示自动消退，关键里程碑需要玩家明确确认。
- 背包已满、工具不足和交互中断提示在准星附近出现；物品获得提示显示在屏幕侧边。

## 4. 准星与交互提示

| 状态 | 表现 |
|---|---|
| 无目标 | 低透明度小点 |
| 可交互 | 准星增强，显示动作与按键 |
| 条件不足 | 显示具体缺少的工具、空间或材料 |
| 持续交互 | 显示交互进度 |
| 交互中断 | 进度消失并给出必要原因 |

颜色不能作为唯一信息来源，文字和图形状态必须同时可辨认。

## 5. 第一人称手持表现

- 摄像机前显示手持工具或当前使用物品。
- 第一人称展示模型与世界掉落模型可共用美术资源，但使用独立位置、缩放和材质配置。
- 工具使用提供基础摆动、命中反馈和音效。
- T0进食与饮水暂不制作专用动作，可使用物品轻微抬起和UI进度表现。
- T0不显示第一人称手臂，只显示悬浮的手持工具或使用物品。
- 空手时不显示视图模型。
- 手持模型不得穿透摄像机或明显遮挡交互目标。

## 6. 完整物品栏

### 打开规则

- 按`Tab`或配置按键打开，世界继续运行。
- 打开后释放鼠标光标，并锁定移动、冲刺、跳跃、摄像机转向、交互和工具使用输入。
- 世界时间、饥饿、口渴、机器和其他世界对象继续运行。
- 再次按键或关闭按钮退出，恢复视角控制。
- 打开物品栏不停止饥饿、口渴、机器、交互对象和世界时间。

### 布局

- 主区域显示当前背包的12、20或30格二维网格，物品可以占用多个连续格。
- Tab界面默认只显示背包窗口，背包窗口右上角显示`制作`按钮。
- 点击`制作`后在背包右侧展开随身制作窗口；背包保持原位，两侧之间使用明确分隔。
- 制作窗口可以独立收起，不关闭背包窗口；退出个人界面时两者一并关闭。
- 背包位置不得因切换到容器界面而改变。
- 6位快捷栏位于屏幕底部中央，饥饿与口渴位于快捷栏上方。
- 界面覆盖大部分操作区域，但使用半透明遮罩并保留画面边缘，使玩家能够观察世界变化。
- 显示背包等级、已用格数和总格数。
- 显示衣物槽、背包槽、左右手位和`3`至`6`号快捷栏绑定。
- 饥饿与口渴继续保持可见。
- 物品详情显示名称、用途、数量、耐久、恢复效果和使用时间。

### 操作

- 左键按住后物品中心吸附鼠标；拖动期间按`R`旋转，松开时按完整轮廓贴合度选择合法落点。
- 悬停物品时在鼠标旁显示名称；搜刮状态悬停按`F`或双击执行背包与容器间快速转移。
- 支持一对多区域置换和一大一小轮廓滑移；失败交换必须原子取消，不得造成物品丢失或无关物品随机跳位。
- 后续补充使用、装备、绑定快捷栏、丢弃和复杂详情；T0不提供堆叠、拆分或一键整理。
- 关闭界面时鼠标持有物返回来源或背包，禁止静默丢失。
- 使用食物或饮水后关闭物品栏，进入世界中的持续使用状态。

## 7. 容器界面

- 左侧固定显示玩家背包，右侧固定显示当前容器。
- 世界继续运行，输入规则与完整物品栏一致。
- 容器内容首次打开时逐件搜索揭示；已揭示物品可以立即转移。
- 首次打开先显示全部自然战利品的完整未知轮廓，空格直接显示为空；当前物品使用环绕放大镜搜索1秒，揭示后短暂高光。
- 支持拖放、旋转和快速转移；T0不提供堆叠与拆分。
- 玩家离开交互距离时自动关闭容器界面。

## 8. 建造模式UI

- 摄像机中心射线确定建造预览落点。
- 底部显示确认、取消、旋转和地基高度调节按键。
- 侧边显示所需材料和当前持有数量。
- 合法、冲突和缺少支撑使用颜色、图标与文字共同反馈。
- 庇护所不显示完整度或有效性，只判断单个组件能否放置。

## 9. 机器与能源UI

- 锅炉显示水、燃料、产汽状态和停机原因。
- 发电机显示蒸汽输入、电力输出、转动状态和电灯连接状态。
- 电动水泵显示供电、水源和输出连接状态；完成有效抽水时以水泵运转和园艺室储水变化作为主要成功反馈。
- 机器面板打开时世界继续运行。

## 10. 现代HUD视觉规范

- 使用清晰几何形、统一间距和有限色彩。
- 正常信息使用中性颜色，警告使用克制的暖色，关键错误使用高对比色。
- 避免大量锈迹边框、仿机械仪表和妨碍阅读的废土装饰。
- 字体、图标和状态条必须支持不同分辨率与UI缩放。
- 晃动、屏幕边缘效果和闪烁提示应允许关闭或降低。

## 11. 扩展约束

- 快捷栏容量、手位数量和位置类型不得在代码中写死；通过配置和存档记录实际数量及`HandSlot`、`InventoryReference`类型。
- HUD从玩家状态事件读取数据，不直接控制背包、生存或机器逻辑。
- 输入在探索、UI、建造和机器界面之间使用明确的输入上下文切换。
- 第一人称视图模型与世界模型逻辑分离。
- FOV、灵敏度、UI缩放和准星样式使用可配置参数。

3. 物品详情采用悬停提示，还是固定详情区域？
