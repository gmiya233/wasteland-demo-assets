# T0 UI原型

本目录保存Wasteland Industrial Demo的可交互UI策划原型，用于策划审核、程序拆分和Unity界面实现参考，不代表最终美术资源。

## 背包与制作

![背包默认状态](背包UI预览.png)

- `Tab`默认只显示玩家背包。
- 背包右上角的`制作`按钮用于展开或收起右侧制作窗口。
- 一级背包为`3×4`无间隙正方形网格。
- 快捷栏`1`、`2`号为左右手实际持有位，不占背包空间；`3`至`6`号为背包物品引用。

![背包内展开制作窗口](背包内制作UI预览.png)

## 容器搜刮

![4×5容器搜刮状态](容器搜刮UI预览.png)

- 搜刮时固定为左侧玩家背包、右侧当前容器。
- 当前通用容器原型为`4×5`正方形网格。
- 容器物品按照从左上到右下的顺序逐件揭示。
- 搜索过程中允许整理背包并取走已经揭示的物品。
