# 背包、制作与容器UI规则

## 界面状态

1. `Tab`打开时默认只显示背包。
2. 点击背包右上角`制作`后，在右侧展开制作窗口。
3. 搜刮世界容器时关闭制作窗口，固定显示左背包、右容器。
4. 界面打开期间世界继续运行，但玩家移动、视角和世界操作输入被锁定。

## 网格

- 一级背包：`4×5`。
- 二级背包：`5×6`。
- 三级背包：`6×7`。
- 通用容器原型：`4×5`。
- 基础格始终为正方形。
- 相邻格无空隙，只显示一条共享边界线。
- 多格物品连续覆盖全部占用格，只绘制一个完整物品外框。
- 背包和容器使用同一套二维占用规则；空格不显示编号，物品卡不显示独立操作按钮。

## 操作

- 左键按住后，物品中心吸附到鼠标中心；拖动期间按`R`旋转。
- 松开时按物品轮廓与合法网格候选的贴合度选择落点，不直接使用鼠标单格或强制吸附目标物品锚点。
- 绿色表示可放置，红色表示无法完成放置或交换；交换物品的次级落点使用冷青色。
- 悬停物品时在鼠标旁显示名称；搜刮界面悬停按`F`或双击执行快速转移。
- 一对多交换只将被覆盖物品放入拖动物品释放的旧轮廓区域，按左上到右下稳定排列。
- 一大一小交换优先使用最短轮廓滑移：长物品保持方向滑动，小物品进入释放格。

## 容器搜索

- 首次打开时立即显示全部战利品的完整未知轮廓，空格直接显示为空。
- 按物品锚点从左上到右下逐件搜索，时间为`1.0秒+0.5秒×（占格数-1）`。
- 不同容器没有搜索速度差异，旋转也不改变搜索时间。
- 当前搜索物品中央显示做圆周移动的简笔放大镜。
- 新揭示物品播放约0.7秒铁锈橙高光，再继续下一件。

## 快捷栏

- 共6位，支持数字键`1`至`6`和鼠标滚轮。
- `1`号为左手位，`2`号为右手位；手持物不占背包网格。
- `3`至`6`号是背包物品引用，不提供额外储存空间。
- 无背包时`3`至`6`号保留布局但使用灰色禁用样式；数字键不可选择，滚轮循环跳过。
- 左右手位和普通引用位必须通过间隔、标签或边界样式形成视觉分组。

## 视觉方向

- 石墨黑和枪灰色半透明面板。
- 低饱和橄榄灰网格。
- 米白色正文。
- 铁锈橙用于选择、制作按钮和主要操作。
- 冷青色用于搜索进度和技术反馈。
- 直角或极小圆角，避免过度锈迹、军事符号和装饰性仪表。
