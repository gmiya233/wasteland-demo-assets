# TECH_T0_003：农业支线

版本：v0.1  
状态：地下水、简易管道和园艺室供水方向已确认；作物配方待讨论

```text
基础园艺
→ 小型园艺室
├→ 橡胶树种植
└→ 地下水源钻探
    → 简易管道
→ 电动抽水
```

## 节点职责

- 基础园艺：开放作物、种植位与手动管理规则。
- 小型园艺室：解锁带固定种植位和进水接口的整体设施。
- 橡胶树种植：使搜刮获得的绝缘橡胶逐步转向可持续农业来源；树苗、产物和加工配方待定。
- 地下水源钻探：解锁郊外地下水钻探点与永久地下水井；T0不模拟枯竭、水质和钻探失败。
- 简易管道：解锁按米制作、堆叠和消耗的通用流体连接物品；可运输所有`Fluid`类型。
- 电动抽水：与科技主线的蒸汽发电和基础电力连接汇合，解锁电动水泵。

小型园艺室自带4000 ml缓存。有水时每tick消耗50 ml并以×1.0速度生产；不足50 ml时不消耗水并以×0.2速度继续生产。

T0农业不模拟复杂温度、湿度、营养液、病虫害或自动收获。其首要作用是建立可持续生产需求，并为第一份工业电力提供明确用途。
