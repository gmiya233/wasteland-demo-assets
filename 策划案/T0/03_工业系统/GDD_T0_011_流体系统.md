# GDD_T0_011：流体系统

版本：v0.2  
状态：T0基础流量、缓存与园艺室供水规则已确认

## 1. 设计目标

流体系统负责流体的产生、连接、传输与消耗，为地下水井、电动水泵、小型园艺室、简易锅炉和蒸汽发电机提供统一接口。水和低压蒸汽均属于“流体”分类。

T0优先验证“设备之间建立有效连接”的玩法，不制作可见的实体管线，也不模拟真实管路物理。系统数据应允许后续增加不同流体、管材、压力等级、容量和多节点网络。

## 2. T0系统边界

- `Fluid`是统一资源分类，T0已有的具体流体为水与低压蒸汽。
- 水使用标签`Fluid.Water`，低压蒸汽使用标签`Fluid.Steam.LowPressure`。
- 简易管道可以运输所有归类为`Fluid`的资源，不与某一种具体流体绑定。
- 管道不显示在世界中，不进行路径、弯头、坡度和障碍检测。
- T0不计算管径、实时压力、温度、泄漏和污染。
- 水源、生产设备、运输连接和消费设备必须使用独立数据定义。
- 所有流体连接使用同一种简易管道物品和两点逻辑连接操作。

## 3. 流体设备与端口

| 设备 | 流体职责 | T0端口 |
|---|---|---|
| 地下水井 | 提供永久地下水源 | 水源输出端 |
| 电动水泵 | 从水源抽水并向用水设备供水 | 水输入端、水输出端 |
| 小型园艺室 | 接收并储存灌溉用水 | 水输入端 |
| 简易锅炉 | 消耗水和燃料，产生低压蒸汽 | 水输入端/手动填充位、蒸汽输出端 |
| 蒸汽发电机 | 消耗低压蒸汽并产生电力 | 蒸汽输入端 |

每个端口至少记录：端口类型、允许流体、输入/输出方向、所属设备实例ID和连接状态。端口数据独立于模型位置，模型仅提供玩家交互点。

## 4. 简易管道物品

- 物品名称：简易管道
- 物品尺寸：1×1
- 计量单位：米
- 1个数量代表1米
- 单格最大堆叠：100米
- 属于普通物品不可堆叠规则的特殊例外

### 4.1 配方

制作1米简易管道需要：

- 铁棍 ×1
- 铁板 ×1
- 铁螺丝 ×1
- 铁锤，成功制作后耐久−1
- 铁螺丝刀，成功制作后耐久−1

制作地点：初级工作站。  
产出：简易管道 ×1米。

## 5. 建立流体连接

1. 玩家手持简易管道，进入管道连接状态。
2. 右键机器A的有效流体端口，将其记录为起点。
3. 右键机器B的兼容流体端口，将其记录为终点。
4. 系统计算两个端口之间的直线距离并向上取整。
5. 背包管道数量充足时，扣除对应米数并建立逻辑连接。
6. 数量不足时不建立连接，显示所需长度、已有长度和缺少长度。
7. 完成或取消后退出本次连接状态。

示例：两个端口相距6.3米，需要消耗7米简易管道。

## 6. 连接规则

- T0连接不在世界中生成管道模型。
- 建筑物、地形和其他机器不会阻挡连接。
- 输入端只能连接兼容的输出端。
- 输出端的流体必须在输入端的允许流体标签中，才能建立或启用连接。
- 每条连接在运行时只运输一种流体；流体类型由当前输出端提供的内容决定。
- 简易管道本身接受所有`Fluid`类型，但机器端口仍可限制具体流体，防止水进入蒸汽输入端等错误连接。
- 同一端口是否允许多条连接由端口数据配置；T0默认单输入、单输出。
- 连接记录必须引用两端设备的稳定实例ID，支持存档与读档。
- 移动或拆除任意一端设备时，连接自动解除。
- 玩家可以在设备界面主动拆除连接。
- 解除连接时返还建立连接所消耗的全部管道。
- 背包无法容纳返还物时，多余管道掉落在玩家附近。

## 7. 地下水源与抽水

- 地下水源钻探科技解锁地下水钻探点和地下水井。
- 地下水井只能在郊外允许钻探的土壤地形建造。
- T0钻探完成后生成永久水源，不设计枯竭、水质差异和失败概率。
- 地下水井不会自行向园艺室供水，必须使用简易管道连接电动水泵进行抽取。
- 水泵必须同时具有“地下水井→水泵”的进水连接、“水泵→用水设备”的出水连接和可用电力，才能持续抽水。
- 一次性电池可以让水泵临时运行；电池规则由电力系统文档负责。

### 7.1 电动水泵数值

- 抽水量：100 ml/tick，即400 ml/s。
- 自带流体缓存：1000 ml。
- 水泵只有在工作状态下才抽水。
- 水泵在同一tick内先从有效水源取得最多100 ml，再把水写入自身缓存，并在可输出时向下游传输最多100 ml。
- 水泵缓存已满且下游无法接收时，水泵暂停抽水并停止耗电。
- 从空缓存填满1000 ml需要10 tick，即2.5秒。

## 8. 小型园艺室供水

- 自带流体缓存：4000 ml。
- 正常供水时消耗：50 ml/tick，即200 ml/s。
- 每个生产tick能够从内部缓存扣除50 ml时，作物生产速度为×1.0。
- 内部缓存不足50 ml时，本tick不消耗水，作物仍以×0.2速度生产。
- 园艺室不会因为缺水完全停止生产。
- 水泵的100 ml/tick产水量高于园艺室的50 ml/tick消耗量；单台持续运行的水泵能够稳定供应一座园艺室并产生50 ml/tick余量。
- 园艺室满水缓存可支持80 tick正常生产，即20秒。

## 9. 流体连接状态与反馈

水路至少具有以下状态：

- 未连接
- 连接有效但水泵未运行
- 正在输水
- 水源无效
- 出水端未连接
- 目标储水已满
- 设备缺少电力

手持简易管道时，高亮附近可连接的流体端口，并用颜色或图标区分当前流体类型。设备界面显示连接对象、连接距离、已投入管道长度、当前流体和停止原因。

## 10. 蒸汽边界

- 简易锅炉把水和燃料转换为低压蒸汽。
- 蒸汽发电机消耗低压蒸汽并输出电力。
- 低压蒸汽是独立流体资源，不与水共用库存。
- 玩家手持简易管道，依次右键锅炉蒸汽输出端和蒸汽发电机输入端，即可建立低压蒸汽连接。
- 建立蒸汽连接时，同样按照两个端口的直线距离向上取整并消耗对应米数的简易管道。
- T0保留产汽速率、蒸汽容量和消费速率字段，具体数值待后续确认。

## 11. T0最小验证流程

供能流体链：向简易锅炉加入水和燃料 → 使用简易管道连接锅炉与蒸汽发电机 → 产生并输送低压蒸汽 → 蒸汽发电机开始发电。

供水流体链：地下水钻探 → 建造地下水井 → 放置电动水泵 → 使用简易管道连接地下水井与水泵 → 使用简易管道连接水泵与小型园艺室 → 为水泵供电 → 水泵完成一次有效抽水 → 园艺室获得水。

无水空转不计入有效抽水。使用一次性电池可以完成临时抽水，但稳定供水仍需要持续电源。

## 12. 后续扩展预留

- 更多流体类型与标签
- 特殊管材兼容性；简易管道始终保持全流体兼容
- 压力和温度等级
- 管道容量与最大吞吐量
- 分流、合流、阀门和储罐
- 水质与净化
- 泄漏、过压和设备故障
- 可见实体管线与自动寻路

以上内容在T0不实现，但不得把程序结构绑定为“只运输水”“只运输水和蒸汽”或“只能连接两种固定机器”。
