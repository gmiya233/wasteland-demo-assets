# GDD_T0_006：建造、机器与生产

版本：v0.3
状态：郊外基地与首块地基规则已更新

## 1. 目标

让玩家建立能够缓解生存压力的小型据点，并最终完成第一套蒸汽发电设施。通用机器模型继续为未来加工设备和自动化预留扩展能力。

## 2. 建造规则

- 从建造菜单选择设施，进入预览状态。
- 预览显示占地、朝向、输入输出端口和放置合法性。
- 建筑组件使用网格吸附；机器和室内设施在合法表面上自由放置并提供吸附辅助。
- 地基允许在限定范围内调整高度，为坡地提供水平建造面。
- 第一个基地必须在郊外允许建造的空旷区域建立，城区与开局住宅不能登记为正式基地。
- 玩家首次成功放置地基时登记基地锚点并开启科技树；强制开局引导此前已在制作简易撬棍时结束。
- T0不检测房屋封闭、屋顶覆盖或庇护所有效性，布局完全由玩家决定。
- 合法条件包括地面支撑、无严重重叠、在允许坡度内且玩家可达。
- 确认时一次性扣除材料并生成设施。
- 取消预览不消耗材料。
- 使用扳手拆除己方设施；T0默认返还全部核心材料，消耗品不返还。
- 装有物品或正在工作的设施拆除前必须确认，内容优先转入玩家背包，剩余落地。

## 4. 通用机器状态

- 未配置：没有有效配方或连接。
- 待机：条件满足但没有任务。
- 缺少输入：原料不足。
- 缺少能源：蒸汽不足。
- 工作中：按周期推进加工。
- 输出堵塞：产物无处存放。
- 禁用：玩家主动关闭。
- 故障：为未来维修系统预留；T0默认不随机故障。

任一暂停状态都必须显示具体原因和恢复条件。

## 5. 机器处理规则

- 机器通过能力标签匹配配方。
- 机器持有输入仓、输出仓、任务状态和能源端口。
- 生产速度和能源消耗来自机器与配方共同计算。
- T0一台机器同时只执行一种配方，允许玩家切换。
- 切换配方不得删除已有物品；不兼容输入需要玩家取出。
- 离开机器界面或离开附近区域不影响生产。

## 6. T0终局设施链

确认关系：水与燃料 → 简易锅炉 → 简易管道输送低压蒸汽 → 蒸汽发电机 → 绝缘铜导线 → 电动水泵；地下水井 → 简易管道 → 电动水泵 → 简易管道 → 小型园艺室。

玩家手动补充锅炉的水和燃料。一次性电池可以临时启动水泵并完成首次抽水测试；只有蒸汽发电机通过绝缘铜导线驱动水泵并向小型园艺室有效供水，才完成T0。无水空转不计入。蒸汽缓冲罐、自动物流和完整电网均不是当前必需项。

### 6.1 首块地基

配方：`铁板×10 + 铁锤捶打加工 → 地基组件×1`。

- 铁板全部消耗。
- 铁锤作为`Tool.Hammer`加工工具，不被消耗；成功完成后扣除1点耐久。
- 基地建立目标只要求放置一块地基，不要求同时建造储物、工作台、床铺、墙体或屋顶。
- 后续设施由科技树引导，围绕基地锚点逐步扩建。

## 7. UI最小信息

- 当前工作模式或配方
- 输入与输出库存
- 加工进度
- 当前工作状态
- 能源输入、输出与连接状态
- 预计产物
- 停机原因

世界空间表现至少包括运行音效、运动部件或蒸汽效果，以及停机状态变化。

## 8. 扩展约束

- 机器核心不引用特定能源实现。
- 端口数据独立于模型朝向，并可映射到模型连接点。
- 机器定义、配方和运行实例分离。
- 模块、升级、多方块结构只保留数据扩展位，T0不实现。
- 每个建造实例具有稳定实例ID用于存档和连接关系。

## 10. 土焦炉

土焦炉使用`焦炉砖×28`建造，不需要铁锤或其他工具。焦炉砖由`石头×1＋泥土×1`制作，因此一座土焦炉总计消耗石头×28和泥土×28。

生产配方为`木材×1 → 木炭×1`，单件加工时间30秒。土焦炉不消耗电力或额外燃料，木材投入已抽象包含热解损耗。玩家关闭界面或离开附近区域后继续生产；输出空间堵塞时暂停，不能继续消耗木材。
