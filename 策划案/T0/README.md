## 文档规则

- `已定`：继承当前项目方向，可直接作为开发依据。
- `建议`：本轮草案给出的设计方案，需要审核。
- `待讨论`：会明显影响体验或开发成本，确认前不作为实现依据。
- T0 只实现残骸时代，但数据结构和系统接口不得绑定单一物品、机器或能源类型。
- 文档负责规则，`Data` 目录负责具体内容与平衡参数。
- 当前主线已确认：缓解衣食住行压力，并以第一台蒸汽发电机成功供电作为T0终点。
- 当前生存数值仅为饥饿和口渴；“行”使用背包格数成长；庇护所使用自由组件；最终负载为拾取的旧电灯。
- 背包容量暂定10/20/30格；饥饿口渴按移动距离消耗且不致死；旧电灯需要维修；庇护所不做结构检测并使用地基平整建造面。
- 背包由探索材料逐级升级；饥渴UI位于物品栏上方；进食饮水有使用时间，可移动使用但会临时减速，暂不制作专用动作。
- 游戏采用第一人称；物品栏不暂停；T0快捷栏6格并可扩展；显示手持工具；HUD采用现代风格。
- 物品栏打开时玩家不能移动且采用局部覆盖；首版只显示悬浮工具；快捷栏支持数字键和鼠标滚轮。
- 物品栏采用类似《Minecraft》的中央下方布局，其余视觉细节暂缓决定。
- 都市资源来自真实世界物体；首个原型由生成点产生的可收纳资源与金属储物柜组成。
- T0资源能力分为可收纳资源、资源容器和大型资源；露天可收纳资源使用生成点布置；汽车完整拆解保留但后置开发。

## 审核顺序

1. 审核总纲中的生存主线、T0终点和范围。
2. 审核衣食住行四项保障的模拟深度。
3. 审核资源、交互、背包和制造规则。
4. 审核锅炉、发电机及最小电力边界。
5. 审核90—120分钟的进程与教学。
6. 最后调整数据表数值。
