## 文档规则

- `已定`：继承当前项目方向，可直接作为开发依据。
- `建议`：本轮草案给出的设计方案，需要审核。
- `待讨论`：会明显影响体验或开发成本，确认前不作为实现依据。
- T0 只实现残骸时代，但数据结构和系统接口不得绑定单一物品、机器或能源类型。
- 文档负责规则，`Data` 目录负责具体内容与平衡参数。
- 当前主线已确认：缓解衣食住行压力，并以第一台蒸汽发电机稳定驱动电动水泵供水作为T0终点。
- 当前生存数值仅为饥饿和口渴；“行”使用背包格数成长；庇护所使用自由组件；T0最终负载为电动水泵。
- 背包容量暂定20/30/42格，对应4×5、5×6、6×7二维网格；饥饿口渴按移动距离消耗且不致死；庇护所不做结构检测并使用地基平整建造面。背包升级材料暂不设计。
- 背包由探索材料逐级升级；饥渴UI位于物品栏上方；进食饮水有使用时间，可移动使用但会临时减速，暂不制作专用动作。
- 游戏采用第一人称；物品栏不暂停；T0快捷栏6位并可扩展，其中1、2号为不占背包网格的左右手位，3至6号为背包物品快捷引用；显示手持工具；HUD采用现代风格。
- 物品栏打开时玩家不能移动且采用局部覆盖；首版只显示悬浮工具；快捷栏支持数字键和鼠标滚轮。
- 背包改用无间隙正方形二维网格和变尺寸物品；Tab默认只显示背包，点击背包右上角制作按钮后在右侧展开制作窗口；搜刮界面固定左侧背包、右侧容器。
- 都市资源来自真实世界物体；第一阶段原型从废弃住宅、场景表面物品、可徒手打开的木柜和室外石头开始。
- T0资源能力分为可收纳资源、资源容器和大型资源；露天可收纳资源使用生成点布置；当前汽车只能用撬棍打开车门和后备箱，完整拆解留待后续。
- 世界以固定出生城市为中心；城市外公路按世界种子向外延伸，城市、石料矿场、基地候选区和稀疏路边建筑依附公路生成。出生城市的32地块战利品模拟不代表整个世界产出。
- 旧版物品、配方和机器成本已经撤销；当前数据表收录本轮确认的生存补给、铁制工具、基础材料、二三级材料和可建造物，尚未讨论的配方成本保持为空。
- 玩家开局没有背包，只有左右手两个持有位；新手住宅固定放置一级背包，内部装有铁铲×1、面包×2、饮用水×2。木制储物柜固定提供铁棍，室外石头用于制作简易撬棍。
- 背包是保留内部物品的独立容器实例；装备、取下、放到地面和再次拾取都不会重置内容，且禁止背包嵌套。
- 强制开局引导在玩家制作简易撬棍后结束；随后设立“铁板×4、泥土×2、铁锤×1”的非强制地基材料目标，由玩家自由探索城市并自行决定何时前往郊外建立基地。成功放置第一块地基后开启科技树。
- 地基组件消耗`铁板×4、泥土×2`并要求铁锤进行捶打加工；新手完成条件不包含储物、工作台、床铺、墙体或屋顶。
- 所有工具最大耐久为`128`，成功使用一次消耗`1`点，耐久归零时自动销毁。
- T0最终以蒸汽发电机通过绝缘铜导线驱动电动水泵，从地下水井抽水并经简易管道向小型园艺室有效供水为时代标志；一次性电池只负责临时启动测试。

## 审核顺序

1. 审核总纲中的生存主线、T0终点和范围。
2. 审核衣食住行四项保障的模拟深度。
3. 审核资源、交互、背包和制造规则。
4. 审核锅炉、发电机及最小电力边界。
5. 审核90—120分钟的进程与教学。
6. 最后调整数据表数值。
