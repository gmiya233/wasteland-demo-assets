# GDD_T0_001：T0玩法总纲

版本：v0.6
状态：新手阶段郊外基地目标已更新，其余材料链待重构

## 1. 阶段定位

**已定**：T0以缓解生存压力为主线。玩家从衣、食、住、行都缺乏保障的状态开始，通过探索、拆解、制造和建造逐项解决生存问题，并第一次把蒸汽转化为电力。

**一句话体验**：从在废墟里勉强过夜的幸存者，成长为能够用第一份工业电力驱动水泵、开始稳定生产的建设者。

工业是解决生存问题的手段，而不是脱离生存需求单独存在的生产任务。T0不追求大型自动化，重点是“准备和建设让明天比今天更安全”。

## 2. 开始与结束

### 开始状态

- 玩家没有工具、食物、背包、固定住所和交通工具，出生时只有左右手两个持有位。
- 新手住宅内固定放置一个一级背包；背包内部固定装有铁铲×1、一袋面包×2和一瓶饮用水×2。
- 住宅内的木制储物柜可徒手打开，柜内固定提供铁棍。
- 住宅外固定提供石头，玩家以铁棍和石头制作第一根简易撬棍。
- 生存需求会造成压力，但开局不应因数值过快下降而打断学习。

### 结束状态

- 衣：拥有完成修补的基础衣物；T0暂不启用体温或环境暴露数值。
- 食：拥有稳定数日的食物和安全饮水获取方式。
- 住：离开城区，在郊外空旷地点放置第一块地基，建立可供后续工业扩建的基地锚点。
- 行：通过20格、30格、42格三个背包等级提升携带能力，逐步扩大单次探索半径。
- 工业：制造并成功启动第一台蒸汽发电机，驱动电动水泵为小型园艺室完成第一次有效供水。

蒸汽发电机通过绝缘铜导线驱动电动水泵，从地下水井抽水并经简易管道送入小型园艺室，是T0结束里程碑。一次性电池只能完成首次临时抽水测试。T0只验证蒸汽发电、基础电力连接、流体连接和第一个生产型用电负载，不要求建立完整电气工业。

## 3. 设计支柱

1. **生存问题驱动制造**：每项制作都对应保暖、饮食、庇护、运输或能源问题。
2. **准备带来安全**：玩家通过规划物资和据点降低风险，而非依靠高强度战斗。
3. **残骸有价值**：不同残骸提供不同材料，探索目标具有可判断性。
4. **劳动逐步升级**：工具和设施提升效率，但T0不强制实现自动物流。
5. **生产可理解**：输入、过程、输出和停机原因必须清晰。
6. **系统可扩展**：内容通过ID、标签、配方和能力组合，不绑定单一时代。

## 3.1 世界结构原则

- 开局使用一座固定路网的出生城市，保证新手住宅、城市探索和郊外出口可控。
- 城市外公路根据世界种子持续向外生成，后续城市、石料矿场、基地候选区和稀疏建筑只能依附公路网络出现。
- 单个城市内部使用手工城区模板与规则化建筑内容；不在运行时随机拼接道路和房间。
- 出生城市、后续城市和公路沿线地点分别结算与验证战利品，不把一座城市的模拟结果外推为全世界资源量。

## 4. 核心循环

感知生存缺口 → 探索并制定准备 → 获取资源 → 制作工具或保障品 → 建立设施 → 缓解压力 → 扩大活动范围 → 接触更高技术需求。

工业子循环：回收材料 → 手工处理 → 制造设备 → 提供热与蒸汽 → 驱动发电机 → 获得第一份电力。

基地科技树在第一块地基放置后开启，分为科技主线与农业支线。科技通过在研究台消耗实验材料解锁，成本通常参考目标配方的原材料及其倍率；两条线路最终在电动水泵向小型园艺室供水时汇合。

T0资源分工为：城区提供金属锭、玻璃、橡胶和工业遗产；郊外提供可持续木材、土壤泥土和石料矿场石头。土焦炉使木材转化为木炭，建立首条基地原料生产链。

## 5. 阶段划分

| 阶段 | 主问题 | 阶段目标 | 新能力 |
|---|---|---|---|
| T0-1 住宅开局 | 缺少补给与工具 | 进食饮水并制作简易撬棍 | 拾取、容器、配方、户外探索 |
| T0-2 工具探索 | 受限区域无法进入 | 使用撬棍并取得铁锤等正式工具 | 工具开启、耐久、初级拆解 |
| T0-3 郊外基地 | 城区缺少工业扩建空间 | 在郊外放置第一块地基 | 基地锚点、科技树入口 |
| T0-4 扩大行动 | 背包格数不足以支持远征 | 将背包升级至42格 | 更远探索、更多携带能力 |
| T0-5 蒸汽发电 | 人力和火力无法提供稳定动力 | 钻探地下水，制造蒸汽发电机并稳定运行电动水泵 | 第一份服务于生产的可用电力与流体网络 |

## 6. T0内容边界

### 必须包含

- 第一人称移动、探索、手持工具和交互
- 拾取、搜索、拆解、采集和工具耐久
- 简化的饥饿与口渴压力
- 食物、水处理、基础衣物修补和庇护所
- 背包格数成长与基地储物
- 徒手、工作台制造与建造
- 地下水井、通用简易管道、锅炉、蒸汽发电机、绝缘铜导线、电动水泵和小型园艺室供水闭环
- 里程碑任务、状态反馈和存档

### 当前不包含

- 正式战斗、基地防御和敌对势力
- 自动物流、传送带或机械滑槽
- 完整电网与电动机器生产线
- 燃油与化学工业
- 真实营养学、疾病模拟和复杂身体部位系统
- 体温、环境暴露和疲劳数值
- 手推车、载具及独立移动技能系统
- 真实热力学、复杂压力和管网流体模拟
- 多人联机、贸易与NPC社会

机械滑槽保留为T0追加候选，不纳入当前验收。

## 7. 体验节奏

- 0—15分钟：进入开局住宅，取得并装备一级背包，使用其中的面包和饮用水，搜索木柜取得铁棍，到室外寻找石头并制作简易撬棍。
- 15—30分钟：理解工具耐久并完成第一次有效拆解。
- 15—60分钟：开局引导结束，玩家自由探索城市并准备铁板×4与可用铁锤；到达郊外后采集泥土×2，制作并放置第一块地基，随后开启科技树。
- 60—90分钟：稳定衣食保障，探索城区并取得园艺室、水泵和发电设施所需材料。
- 90—120分钟：制造锅炉、蒸汽发电机与电动水泵，为小型园艺室完成第一次供水。

目标总时长已确认为90—120分钟，后续通过试玩校准资源数量。

## 8. 已确认规则

- T0主线为缓解衣食住行压力。
- T0终点为使用蒸汽发电机供电，使电动水泵完成一次有效抽水并把水送入小型园艺室。
- 工具耐久启用；仅在有效使用时消耗，并提供损坏预警。
- 自动物流暂不实现，未来可作为T0追加内容。
- “行”采用背包格数成长，不制作T0载具或手推车。
- 生存数值暂时只有饥饿和口渴。
- 电力测试使用玩家制造并放置的电动水泵，旧电灯退出T0主线必做范围。
- 庇护所采用自由建筑组件。
- 背包分为20格、30格和42格三级；网格暂定4×5、5×6和6×7。
- 饥饿与口渴按移动距离消耗，只影响移动速度，归零不致死。
- 电动水泵必须通过简易管道连接地下水井与小型园艺室，并通过绝缘铜导线取得蒸汽发电机供电；空转或仅使用一次性电池不能完成T0里程碑。
- 庇护所不检测结构有效性，地基组件负责提供平整建造面。
- 开局住宅不能登记为正式基地；第一个基地必须建立在郊外允许建造的空旷区域。
- 强制开局引导在玩家制作简易撬棍时结束；地基属于后续自由探索目标，不属于强制新手教学。
- 基地建立只以成功放置一块地基为完成条件，不要求墙体、屋顶、储物、工作台或休息点。
- 地基组件使用`铁板×4、泥土×2`制作，并要求铁锤提供捶打加工能力。
- 背包升级由探索材料逐步解锁。
- 开局无背包时只有左右手两个持有位；背包作为独立可装备容器保存自己的内部物品，取下和丢弃不会清空内容。
- 饥饿和口渴显示在物品栏上方。
- 进食饮水具有使用时间，允许移动使用但会临时减速；T0暂不制作专用角色动作。
- 完整物品栏和机器界面不暂停世界。
- T0快捷栏为6位并预留后续升级；`1`、`2`号模拟左右手且不占背包网格，`3`至`6`号为背包物品快捷引用。
- HUD采用简洁现代风格。
- 物品栏打开时世界继续运行，但玩家不能移动或执行世界操作。
- 第一人称首版只显示悬浮手持工具，不显示手臂。
- 快捷栏支持数字键与鼠标滚轮；物品栏只覆盖部分屏幕。
- `Tab`默认只打开背包窗口；点击背包右上角`制作`按钮后，制作窗口在右侧展开。
- 旧版材料与配方全部撤销；当前有效内容以物品、配方和机器数据表及已经确认的系统文档为准。

## 9. 原型验收标准

- 玩家能说明每项关键设施解决了哪个生存问题。
- 生存压力能推动行动，但不会在教程阶段频繁致死。
- 衣食住行四项均至少有一个可获得、可使用且能验证效果的解决方案；其中只有饥饿和口渴作为持续下降的生存数值。
- 工具耐久消耗、警告、损坏和重新制造流程完整。
- 蒸汽发电机能完成从燃料和水到蒸汽、电力，再到水泵为园艺室供水的闭环。
- 保存并加载后，需求值、耐久、容器、设施和里程碑状态正确恢复。
- 新增物品、配方、机器和需求效果无需修改核心交互代码。
