# GDD_T0_001：T0玩法总纲

版本：v0.2  
状态：审核中

## 1. 阶段定位

**已定**：T0以缓解生存压力为主线。玩家从衣、食、住、行都缺乏保障的状态开始，通过探索、拆解、制造和建造逐项解决生存问题，并第一次把蒸汽转化为电力。

**一句话体验**：从在废墟里勉强过夜的幸存者，成长为能够点亮第一盏工业电灯的建设者。

工业是解决生存问题的手段，而不是脱离生存需求单独存在的生产任务。T0不追求大型自动化，重点是“准备和建设让明天比今天更安全”。

## 2. 开始与结束

### 开始状态

- 玩家只有破旧基础服装，没有工具、食物储备、固定住所和交通工具。
- 周边有相对安全的废墟、自然资源和可搜索容器。
- 玩家只能拾取、搜索和低效率徒手拆解。
- 生存需求会造成压力，但开局不应因数值过快下降而打断学习。

### 结束状态

- 衣：拥有可修补的基础防护衣物，能应对T0常见环境。
- 食：拥有稳定数日的食物和安全饮水获取方式。
- 住：拥有可保存、休息、储物和避雨的固定庇护所。
- 行：拥有降低搬运或远征成本的基础出行方案。
- 工业：制造并成功启动第一台蒸汽发电机，产生第一份可用电力。

蒸汽发电机是T0结束里程碑。T0只验证发电、储存或点亮测试负载，不要求建立完整电气工业。

## 3. 设计支柱

1. **生存问题驱动制造**：每项制作都对应保暖、饮食、庇护、运输或能源问题。
2. **准备带来安全**：玩家通过规划物资和据点降低风险，而非依靠高强度战斗。
3. **残骸有价值**：不同残骸提供不同材料，探索目标具有可判断性。
4. **劳动逐步升级**：工具和设施提升效率，但T0不强制实现自动物流。
5. **生产可理解**：输入、过程、输出和停机原因必须清晰。
6. **系统可扩展**：内容通过ID、标签、配方和能力组合，不绑定单一时代。

## 4. 核心循环

感知生存缺口 → 探索并制定准备 → 获取资源 → 制作工具或保障品 → 建立设施 → 缓解压力 → 扩大活动范围 → 接触更高技术需求。

工业子循环：回收材料 → 手工处理 → 制造设备 → 提供热与蒸汽 → 驱动发电机 → 获得第一份电力。

## 5. 阶段划分

| 阶段 | 主问题 | 阶段目标 | 新能力 |
|---|---|---|---|
| T0-1 赤手求生 | 食物、水和夜间安全 | 安全度过第一天 | 拾取、搜索、徒手制作 |
| T0-2 衣食保障 | 环境暴露和补给不稳定 | 修补衣物、处理水、储备食物 | 工具拆解、烹饪、修补 |
| T0-3 固定住所 | 无安全存档与储存点 | 建成基础庇护所 | 休息、储物、基础工作台 |
| T0-4 扩大行动 | 远处资源搬运成本高 | 获得基础出行/搬运方案 | 更远探索、更多携带能力 |
| T0-5 蒸汽发电 | 人力和火力无法提供稳定动力 | 制造并启动蒸汽发电机 | 第一份可用电力 |

## 6. T0内容边界

### 必须包含

- 第三人称移动、探索和交互
- 拾取、搜索、拆解、采集和工具耐久
- 简化的饥饿、口渴、体温/暴露与疲劳压力
- 食物、水处理、基础衣物修补和庇护所
- 背包、储物和一种基础出行/搬运方案
- 徒手、工作台制造与建造
- 简化锅炉、蒸汽发电机和最小电力验证负载
- 里程碑任务、状态反馈和存档

### 当前不包含

- 正式战斗、基地防御和敌对势力
- 自动物流、传送带或机械滑槽
- 完整电网与电动机器生产线
- 燃油与化学工业
- 真实营养学、疾病模拟和复杂身体部位系统
- 真实热力学、复杂压力和管网流体模拟
- 多人联机、贸易与NPC社会

机械滑槽保留为T0追加候选，不纳入当前验收。

## 7. 体验节奏

- 0—15分钟：取得水、食物和第一件工具。
- 15—30分钟：理解工具耐久并完成第一次有效拆解。
- 30—60分钟：建立工作台、储物和可休息庇护所。
- 60—90分钟：稳定衣食保障，并完成基础出行/搬运方案。
- 90—120分钟：制造锅炉和蒸汽发电机，成功产生第一份电力。

目标总时长已确认为90—120分钟，后续通过试玩校准资源数量。

## 8. 已确认规则

- T0主线为缓解衣食住行压力。
- T0终点为制造并成功启动第一台蒸汽发电机。
- 工具耐久启用；仅在有效使用时消耗，并提供损坏预警。
- 自动物流暂不实现，未来可作为T0追加内容。

## 9. 原型验收标准

- 玩家能说明每项关键设施解决了哪个生存问题。
- 生存压力能推动行动，但不会在教程阶段频繁致死。
- 衣食住行四项均至少有一个可获得、可使用且能验证效果的解决方案。
- 工具耐久消耗、警告、损坏和重新制造流程完整。
- 蒸汽发电机能完成从燃料和水到蒸汽、再到电力输出的闭环。
- 保存并加载后，需求值、耐久、容器、设施和里程碑状态正确恢复。
- 新增物品、配方、机器和需求效果无需修改核心交互代码。

## 10. 待讨论

1. T0的“行”采用手推车、背包架，还是两者组合？
2. 饥饿、口渴、体温和疲劳分别产生什么惩罚，是否允许致死？
3. 蒸汽发电机的首个测试负载采用电灯、无线电还是简易蓄电池？
4. 庇护所采用整套预制建筑，还是墙、地板、屋顶组件建造？
