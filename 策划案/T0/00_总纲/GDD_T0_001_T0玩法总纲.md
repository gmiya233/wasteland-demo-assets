# GDD_T0_001：T0玩法总纲

版本：v0.4
状态：第一阶段已更新，其余材料链待重构

## 1. 阶段定位

**已定**：T0以缓解生存压力为主线。玩家从衣、食、住、行都缺乏保障的状态开始，通过探索、拆解、制造和建造逐项解决生存问题，并第一次把蒸汽转化为电力。

**一句话体验**：从在废墟里勉强过夜的幸存者，成长为能够点亮第一盏工业电灯的建设者。

工业是解决生存问题的手段，而不是脱离生存需求单独存在的生产任务。T0不追求大型自动化，重点是“准备和建设让明天比今天更安全”。

## 2. 开始与结束

### 开始状态

- 玩家没有工具、食物储备、固定住所和交通工具，出生在一栋废弃住宅附近。
- 住宅固定提供一袋面包、一瓶饮用水和一个可徒手打开的木制储物柜；柜内固定提供铁棍。
- 住宅外固定提供石头，玩家以铁棍和石头制作第一根简易撬棍。
- 生存需求会造成压力，但开局不应因数值过快下降而打断学习。

### 结束状态

- 衣：拥有完成修补的基础衣物；T0暂不启用体温或环境暴露数值。
- 食：拥有稳定数日的食物和安全饮水获取方式。
- 住：拥有可保存、休息、储物和避雨的固定庇护所。
- 行：通过12格、20格、30格三个背包等级提升携带能力，逐步扩大单次探索半径。
- 工业：制造并成功启动第一台蒸汽发电机，产生第一份可用电力。

蒸汽发电机是T0结束里程碑。T0只验证发电并点亮从废墟中捡回的旧电灯，不要求建立完整电气工业。

## 3. 设计支柱

1. **生存问题驱动制造**：每项制作都对应保暖、饮食、庇护、运输或能源问题。
2. **准备带来安全**：玩家通过规划物资和据点降低风险，而非依靠高强度战斗。
3. **残骸有价值**：不同残骸提供不同材料，探索目标具有可判断性。
4. **劳动逐步升级**：工具和设施提升效率，但T0不强制实现自动物流。
5. **生产可理解**：输入、过程、输出和停机原因必须清晰。
6. **系统可扩展**：内容通过ID、标签、配方和能力组合，不绑定单一时代。

## 4. 核心循环

感知生存缺口 → 探索并制定准备 → 获取资源 → 制作工具或保障品 → 建立设施 → 缓解压力 → 扩大活动范围 → 接触更高技术需求。

工业子循环：回收材料 → 手工处理 → 制造设备 → 提供热与蒸汽 → 驱动发电机 → 获得第一份电力。

## 5. 阶段划分

| 阶段 | 主问题 | 阶段目标 | 新能力 |
|---|---|---|---|
| T0-1 住宅开局 | 缺少补给与工具 | 进食饮水并制作简易撬棍 | 拾取、容器、配方、户外探索 |
| T0-2 工具探索 | 受限区域无法进入 | 使用撬棍并取得羊角锤等正式工具 | 工具开启、耐久、初级拆解 |
| T0-3 固定住所 | 无安全存档与储存点 | 建成基础庇护所 | 休息、储物、基础工作台 |
| T0-4 扩大行动 | 背包格数不足以支持远征 | 将背包升级至30格 | 更远探索、更多携带能力 |
| T0-5 蒸汽发电 | 人力和火力无法提供稳定动力 | 制造并启动蒸汽发电机 | 第一份可用电力 |

## 6. T0内容边界

### 必须包含

- 第一人称移动、探索、手持工具和交互
- 拾取、搜索、拆解、采集和工具耐久
- 简化的饥饿与口渴压力
- 食物、水处理、基础衣物修补和庇护所
- 背包格数成长与基地储物
- 徒手、工作台制造与建造
- 简化锅炉、蒸汽发电机和可拾取旧电灯测试负载
- 里程碑任务、状态反馈和存档

### 当前不包含

- 正式战斗、基地防御和敌对势力
- 自动物流、传送带或机械滑槽
- 完整电网与电动机器生产线
- 燃油与化学工业
- 真实营养学、疾病模拟和复杂身体部位系统
- 体温、环境暴露和疲劳数值
- 手推车、载具及独立移动技能系统
- 真实热力学、复杂压力和管网流体模拟
- 多人联机、贸易与NPC社会

机械滑槽保留为T0追加候选，不纳入当前验收。

## 7. 体验节奏

- 0—15分钟：搜索开局住宅，取得面包、饮用水和铁棍，到室外寻找石头并制作简易撬棍。
- 15—30分钟：理解工具耐久并完成第一次有效拆解。
- 30—60分钟：建立工作台、储物和可休息庇护所。
- 60—90分钟：稳定衣食保障，逐步升级背包，并从远处废墟取回损坏的旧电灯和发电机材料。
- 90—120分钟：制造锅炉和蒸汽发电机，成功点亮旧电灯。

目标总时长已确认为90—120分钟，后续通过试玩校准资源数量。

## 8. 已确认规则

- T0主线为缓解衣食住行压力。
- T0终点为制造并成功启动第一台蒸汽发电机。
- 工具耐久启用；仅在有效使用时消耗，并提供损坏预警。
- 自动物流暂不实现，未来可作为T0追加内容。
- “行”采用背包格数成长，不制作T0载具或手推车。
- 生存数值暂时只有饥饿和口渴。
- 电力测试使用废墟中拾取的旧电灯。
- 庇护所采用自由建筑组件。
- 背包分为12格、20格和30格三级；网格暂定3×4、4×5和5×6。
- 饥饿与口渴按移动距离消耗，只影响移动速度，归零不致死。
- 旧电灯必须维修后才能接电。
- 庇护所不检测结构有效性，地基组件负责提供平整建造面。
- 背包升级由探索材料逐步解锁。
- 饥饿和口渴显示在物品栏上方。
- 进食饮水具有使用时间，允许移动使用但会临时减速；T0暂不制作专用角色动作。
- 完整物品栏和机器界面不暂停世界。
- T0快捷栏为6格，并预留后续升级。
- HUD采用简洁现代风格。
- 物品栏打开时世界继续运行，但玩家不能移动或执行世界操作。
- 第一人称首版只显示悬浮手持工具，不显示手臂。
- 快捷栏支持数字键与鼠标滚轮；物品栏只覆盖部分屏幕。
- 旧版材料与配方全部撤销；新数据从已确认的八种物品和一条简易撬棍配方重新建立。

## 9. 原型验收标准

- 玩家能说明每项关键设施解决了哪个生存问题。
- 生存压力能推动行动，但不会在教程阶段频繁致死。
- 衣食住行四项均至少有一个可获得、可使用且能验证效果的解决方案；其中只有饥饿和口渴作为持续下降的生存数值。
- 工具耐久消耗、警告、损坏和重新制造流程完整。
- 蒸汽发电机能完成从燃料和水到蒸汽、再到点亮旧电灯的闭环。
- 保存并加载后，需求值、耐久、容器、设施和里程碑状态正确恢复。
- 新增物品、配方、机器和需求效果无需修改核心交互代码。
