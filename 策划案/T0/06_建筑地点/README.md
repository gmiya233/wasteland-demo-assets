# T0建筑与地点设计索引

本目录专门记录城区、郊外及其他可探索地点的空间与资源设计。

建筑文档负责：

- 地点定位与建筑规模。
- 可进入区域和入口条件。
- 露天物品生成位置类型。
- 容器种类与布置位置。
- 地点资源倾向。
- 可拆构件和大型资源边界。
- 固定教学变体与普通实例的区别。

建筑文档不负责：

- 定义物品基础属性，统一引用`Data/DB_T0_001_Items.csv`。
- 定义通用拾取、容器搜索和拆解规则，统一引用`01_世界交互`。
- 定义背包、快捷栏和容器UI操作，统一引用`02_物品制造`。
