# GDD_T0_008：进程、任务与教学

版本：v0.3  
状态：审核中

## 1. 目标

用生存缺口自然产生任务动机：玩家不是为了清单制作物品，而是因为缺水、寒冷、无处休息或搬运困难，主动寻找解决方案。

## 2. 五个主里程碑

### T0-1：度过第一天

体验目标：学会移动、观察、拾取、搜索和进食饮水。

- 在安全废墟取得应急食物与水。
- 收集木材、纤维、石块和松散废钢。
- 制作简易石锤并点燃火堆。

完成条件：恢复一次饥饿或口渴，制作一件工具并拥有临时热源。

### T0-2：衣食保障

体验目标：将一次性战利品转化为更可靠的生存准备。

- 制作撬棍并拆解指定残骸。
- 煮沸生水并加工一份安全食物。
- 修补基础衣物；T0通过装备成长表达“衣”，暂不启用体温数值。
- 经历一次工具低耐久警告，并完成维修或替换。

完成条件：安全饮水、可食用补给和修补衣物同时满足最低储备。

### T0-3：建立住所

体验目标：获得固定、安全且可积累的据点。

- 建造或修复有效庇护所。
- 放置床铺、储物箱和工作台。
- 在庇护所内休息并完成一次存档状态验证。

完成条件：庇护所被系统判定有效，且玩家使用过休息、储物和工作台功能。

### T0-4：扩大行动范围

体验目标：通过背包格数成长解决远距离资源获取和搬运成本。

- 将背包从10格逐步升级至20格和30格。
- 前往较远废墟取得铜线、机械碎件，并捡回一盏损坏的旧电灯。
- 将资源安全运回据点。

完成条件：30格背包容量生效，并完成一次远征，带回关键材料和损坏的旧电灯。

### T0-5：点亮废土

体验目标：完成从生存保障到早期能源文明的跨越。

- 手工加工锅炉与发电机所需部件。
- 建造锅炉和蒸汽发电机。
- 准备水和燃料，启动锅炉。
- 将蒸汽输入发电机。
- 使用工作台、铜线与扳手维修捡回的旧电灯。
- 接入修好的旧电灯并供电。

完成条件：蒸汽发电机首次稳定输出电力，旧电灯连续点亮规定时间。

## 3. 目标节奏

| 时间 | 预期体验 | 关键概念 |
|---|---|---|
| 0—15分钟 | 应急饮食、第一件工具和火堆 | 交互、需求、徒手制作 |
| 15—30分钟 | 工具拆解、煮水、修补衣物 | 耐久、加工、生存效果 |
| 30—60分钟 | 建立庇护所 | 建造、储物、休息 |
| 60—90分钟 | 背包扩容并完成远征 | 格数规划、路线、资源识别 |
| 90—120分钟 | 锅炉、发电机和旧电灯 | 蒸汽、电力、阶段完成 |

## 4. 教学原则

- 先表现问题，再给出解决途径。
- 首次出现需求时只引导一个主要解决办法，随后允许替代方案。
- 新配方说明它解决的生存问题。
- 背包升级配方在玩家取得对应探索材料后揭示，让探索发现推动容量成长。
- 任务追踪显示目的、条件和当前阻碍，不强制唯一顺序。
- 状态效果必须说明来源、影响与恢复方法。
- 教程可回看，非关键提示可关闭。

## 5. 防卡死

- 起始区存在固定的食物、水、燃料和工具材料保底。
- 关键工具损坏后仍可通过徒手或低级工具重建。
- 生存需求首次生效前预留教学宽限时间。
- 关键设施拆除返还核心材料。
- 提前完成的里程碑条件可以追认。
- 发电机关键材料和旧电灯来自确定性探索点，不依赖随机掉落。

## 6. T0完成反馈

- 发电机启动后，捡回的旧电灯点亮并触发阶段总结。
- 总结展示衣、食、住、行四项压力如何得到缓解。
- 展示从徒手、工具、火力、蒸汽到电力的能力变化。
- 开放后续时代入口占位，但不承诺具体内容。
- 玩家可继续探索、补给和改善据点。

## 7. 已确认

- 目标体验时长：90—120分钟。
- 工具耐久启用。
- 自动物流不属于当前T0必做项。
- T0完成事件：第一台蒸汽发电机成功供电。
- “行”采用背包格数升级。
- 生存数值只启用饥饿和口渴。
- 测试负载是废墟中拾取的旧电灯。
- 庇护所采用自由建筑组件。
- 背包三级容量为10格、20格、30格。
- 饥饿和口渴按移动距离消耗，归零不致死。
- 庇护所不执行结构有效性检测。
- 饥饿与口渴显示在物品栏上方。
- 进食饮水有使用时间，允许移动使用并临时减速，T0暂不制作专用动作。
